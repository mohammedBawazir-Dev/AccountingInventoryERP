# دليل إعداد استضافة تجريبية مجانية (Render + Azure SQL)

> هذا دليل تجهيز وليس عملية نشر مكتملة. لا يحتوي المشروع على بيانات دخول لأي حساب استضافة، ولا يمكن إنشاء رابط عام قبل موافقة مالك الحساب وربط مزودي الاستضافة.

## سبب اختيار هذا المسار

- يتضمن المشروع `Dockerfile` يثبت PHP 8.4 وMicrosoft ODBC Driver 18 وامتداد `pdo_sqlsrv` على خادم Linux.
- يمكن نشر خدمة الويب على Render كخدمة Docker مجانية للاختبار، مع مراعاة النوم/الإيقاف والحدود الشهرية للخطة المجانية.
- يمكن نقل قاعدة البيانات إلى Azure SQL Database المجانية؛ يجب إنشاء قاعدة جديدة على العرض المجاني، ثم استيراد بنية وبيانات قاعدة المشروع إليها.

## تجهيز قاعدة البيانات

1. أنشئ Azure SQL Database جديدة واختر العرض المجاني (Free tier) إن ظهر لحسابك.
2. أنشئ SQL Server Login مخصصًا للتطبيق، ولا تستخدم حساب الإدارة الرئيسي.
3. امنح مستخدم التطبيق أقل الصلاحيات اللازمة على قاعدة المشروع، ومنها قراءة/إضافة/تعديل/حذف جداول الأعمال وإنشاء/تحديث جداول `AppUsers` و`AppUserPermissions` عند الحاجة.
4. انقل مخطط قاعدة البيانات والبيانات من نسخة SSMS المحلية إلى قاعدة Azure SQL الجديدة باستخدام طريقة نشر/استيراد متوافقة مع قاعدة البيانات.
5. من إعدادات Networking / Firewall في Azure SQL، اسمح فقط بعناوين الخروج الخاصة بخدمة الويب قدر الإمكان. لا تفتح قاعدة البيانات للعامة بلا قيود.
6. اختبر اتصال SSMS بقاعدة Azure SQL قبل توصيل التطبيق.

## نشر الموقع على Render

1. ضع نسخة المشروع في مستودع GitHub خاص (Private). لا تستخدم مستودعًا عامًا، ولا ترفع كلمات مرور أو نسخ SQL احتياطية أو ملفات إعدادات سرية.
2. في Render أنشئ Web Service جديدة من المستودع، واختر Runtime / Environment: Docker. سيُستخدم `Dockerfile` الموجود في جذر المشروع، ويضبط `docker-entrypoint.sh` منفذ Apache تلقائيًا من متغير `PORT`.
3. أضف متغيرات البيئة التالية في إعدادات الخدمة:
   - `ERP_DB_SERVER`: عنوان خادم Azure SQL مع المنفذ عند الحاجة.
   - `ERP_DB_NAME`: اسم قاعدة البيانات.
   - `ERP_DB_USERNAME`: مستخدم SQL المخصص للتطبيق.
   - `ERP_DB_PASSWORD`: كلمة مرور مستخدم SQL.
   - `ERP_DB_ENCRYPT`: `yes`.
   - `ERP_DB_TRUST_CERT`: `no`.
4. بعد اكتمال البناء، افتح رابط الخدمة واختبر تسجيل الدخول وفحص الاتصال وشاشات المستخدمين والصلاحيات.
5. لا ترسل إلى الدكتور رابط المستودع؛ أرسل رابط Render فقط. يمكن أن يبقى مستودع المصدر خاصًا. ملاحظة: دخول المدير بالبريد فقط لا يحمي الموقع من أي شخص يعرف هذا البريد؛ لا تنشر الرابط للعامة دون بوابة وصول خاصة.

## حدود الخطة المجانية

- خدمات Render المجانية مناسبة للعرض والاختبار، وقد تدخل في وضع السكون أو تتوقف عند استهلاك حصة الاستخدام، ولا ينبغي اعتمادها كنظام مالي إنتاجي.
- Azure SQL Free له حدود استهلاك شهرية. فعّل سلوك الإيقاف/الإيقاف المؤقت عند بلوغ الحد حتى لا تتحول الخدمة إلى تكلفة مدفوعة.
- لا ترفع قاعدة SQL Server المحلية أو ملف `.bak` إلى مجلد الويب.

## ملاحظات قبل النشر

- قاعدة بيانات XAMPP/SSMS المحلية التي تتصل عبر Windows Integrated Authentication لا يمكن الوصول إليها مباشرة من خادم استضافة بعيد. يلزم نقلها إلى SQL Server/Azure SQL يمكن الوصول إليه عبر الشبكة وتكوين SQL Authentication آمن.
- يحتاج خادم PHP إلى امتداد `pdo_sqlsrv` ومكتبات Microsoft ODBC. وجود PHP فقط لا يكفي.
- ملفات `config`, `app`, `resources`, `database` لا تُعد جذور الويب؛ Dockerfile يضبط DocumentRoot ليكون `public/` فقط.
